# Changelog

All notable changes to Assistant Worker will be documented in this file.

## [1.0.0] - 2026-10-03

### Added
- Gemini Live voice assistant
- Modern PyQt6 interface
- Right-side voice interaction panel
- VoiceOrb visualization
- Microphone input meter
- Interrupt-to-talk
- Windows automation
- System controls
- Reminders
- System tray
- Start-with-Windows support
- Single-instance handling
- Windows installer
